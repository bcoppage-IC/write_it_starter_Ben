WRITE IT FROM A BLANK FILE (Cycle 60 optional workshop)

Set up (do this before the session):
1. Unzip this folder. Open the folder itself in VS Code (File > Open Folder).
2. Open a terminal in VS Code. If you see "running scripts is disabled", click the arrow
   next to the + in the terminal panel and pick Command Prompt, then try again.
3. Type:  npm install
4. Type:  node -v     (you want 20 or higher)

What is already here:
- io.js                 gives you the ask() function. You do not edit it.
- check-calculator.js   a self-check you run after you write calculator.js
- run-calculator.js     runs your calculator
- run-guessing-game.js  runs your guessing game

Everything else you write yourself, starting from a blank file.

House rule for Claude in this session: ask it to EXPLAIN a line or an error message.
Do not ask it to write the program. You are here to practice writing.

At the prompts, type your answers. Pasting into the prompt can scramble the input.
